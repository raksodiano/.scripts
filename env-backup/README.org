* env-backup

Find, package and restore =.env= files across multiple projects.

The command scans a base directory (including subdirectories), collects every
=.env= and =.env.*= file in a deterministic order, stores them in a =tar.gz=
with a manifest, and can later put each file back at its original absolute path.

Template files such as =.env.example=, =.env.sample= and =.env.template= are
excluded by default. A restored file always keeps its original name. If a file
already exists at the destination, only that existing conflicting file is
renamed to =<file>.bak.<timestamp>=; if there is no conflict, the file is simply
restored.

** Usage:

#+begin_src bash
env-backup pack    -d <directory> [-o archive.tar.gz] [-r depth] [-x "dir1,dir2"] [-e "pattern1,pattern2"] [-n] [-l logfile]
env-backup restore -a <archive.tar.gz> [-f] [-n] [-l logfile]
env-backup undo    [-f] [-n] [-l logfile]
env-backup list    -a <archive.tar.gz>
env-backup help
#+end_src

** Commands:

| Command   | Description                                                          |
|-----------+----------------------------------------------------------------------|
| =pack=      | Find and package =.env= / =.env.*= files in a deterministic order      |
| =restore=   | Restore the packaged files to their original absolute paths          |
| =undo=      | Revert the most recent restore using its recorded backups            |
| =list=      | Show the files contained in an archive                               |
| =help=      | Show the help message                                                |

** Pack options:

| Option          | Description                                                                  |
|-----------------+------------------------------------------------------------------------------|
| =-d <directory>=  | Base directory to scan (default: current directory)                          |
| =-o <file>=       | Output archive path (default: =env-backup-<base>-<timestamp>.tar.gz=)          |
| =-r <depth>=      | Maximum search depth (default: unlimited)                                    |
| =-x "dir1,dir2"=  | Additional directories to exclude (comma-separated)                          |
| =-e "p1,p2"=      | Extra file glob patterns to exclude, e.g. ="*.local,*.secret"=                 |
| =-n=              | Dry-run mode (list files without creating the archive)                       |
| =-l <logfile>=    | Log output to file                                                           |
| =-h=              | Show help message                                                            |

Default excluded directories: =.git=, =node_modules=, =vendor=, =dist=,
=build=, =venv=, =.venv=, =__pycache__=, =.cache=.

Default excluded patterns: =*.example=, =*.example.*=, =*.sample=,
=*.sample.*=, =*.template=, =*.template.*=, =*.bak= and =*.bak.*=.

** Restore options:

| Option          | Description                                                                  |
|-----------------+------------------------------------------------------------------------------|
| =-a <file>=       | Archive to restore                                                           |
| =-f=, =--force=    | Restore even if the checksum does not match                                  |
| =-n=              | Dry-run mode (show actions without writing)                                  |
| =-l <logfile>=    | Log output to file                                                           |
| =-h=              | Show help message                                                            |

** Undo options:

| Option          | Description                                                                  |
|-----------------+------------------------------------------------------------------------------|
| =-f=, =--force=    | Undo even if a file changed after the restore                                |
| =-n=              | Dry-run mode (show actions without writing)                                  |
| =-l <logfile>=    | Log output to file                                                           |
| =-h=              | Show help message                                                            |

=undo= reverts the last recorded restore: it puts each backup back at its
original path and removes files that did not exist before the restore. Running
=undo= again reverts the previous restore. Journals are stored under
=~/.local/state/env-backup/restores/= (or =$XDG_STATE_HOME=), while backups stay
next to the original file as =<file>.bak.<timestamp>=.

** Examples:

Package every =.env= under =~/projects=:
#+begin_src bash
env-backup pack -d ~/projects
#+end_src

Choose the output file and exclude extra directories:
#+begin_src bash
env-backup pack -d ~/projects -o ~/envs.tar.gz -x "node_modules,.git,tmp"
#+end_src

Preview what would be packaged, excluding additional local-only files:
#+begin_src bash
env-backup pack -d ~/projects -e "*.local,*.secret" -n
#+end_src

List the contents of an archive:
#+begin_src bash
env-backup list -a ~/envs.tar.gz
#+end_src

Preview a restore:
#+begin_src bash
env-backup restore -a ~/envs.tar.gz -n
#+end_src

Restore the files to their original locations:
#+begin_src bash
env-backup restore -a ~/envs.tar.gz
#+end_src

Preview what the last restore would revert:
#+begin_src bash
env-backup undo -n
#+end_src

Undo the last restore:
#+begin_src bash
env-backup undo
#+end_src

Undo even if the files were modified after the restore:
#+begin_src bash
env-backup undo --force
#+end_src

** Archive format:

#+begin_src text
manifest.tsv
README.txt
files/<relative-path>
#+end_src

=manifest.tsv= is a tab-separated file. Its first lines are comments with the
base directory and creation date, followed by one line per file:

#+begin_src text
INDEX  ABSOLUTE_PATH  RELATIVE_PATH  SIZE  SHA256  MODE  MTIME  ARCHIVE_PATH
#+end_src

Files are sorted with =LC_ALL=C sort= on their relative paths, so the order is
stable across runs and restores follow that same order.

** Restore behavior:

1. The archive is extracted to a temporary directory and its members are
   validated (no absolute paths, no =../= traversal, only expected members).
2. Each entry in =manifest.tsv= is processed in order.
3. If a destination file already exists, only that conflicting file is renamed
   in place to =<file>.bak.<timestamp>=. Then the archived file is written using
   its original name. If there is no conflict, the file is simply restored and
   nothing is renamed.
4. Only real environment files are restored: =name= must be =.env= or start
   with =.env.=. Templates (=.env.example=, =.env.docker.example=, =.env.sample=,
   =.env.template=) and backup copies (=.env.bak.*=) are ignored even if they
   exist in an older archive.
5. The SHA-256 stored in the manifest is verified. On mismatch the file is
   skipped unless =-f= / =--force= is used.
6. Parent directories are created as needed and the original mode is restored.
7. A journal is saved under =~/.local/state/env-backup/restores/= so the restore
   can be reverted with =env-backup undo=.

** Security notes:

- Archives contain secrets in plain text. The script creates them with mode
  =600=, but you are responsible for storing and transferring them safely.
- The restore operation writes to the original absolute paths recorded at pack
  time. Make sure the environment is the one you expect.
- Use =-n= to preview both =pack= and =restore= before running them for real.
- The restored =.env= is never renamed. Only a pre-existing file at the same
  path is renamed to =<file>.bak.<timestamp>=. Those backups contain secrets too,
  so review and remove them when appropriate.
- Undo journals store absolute paths and checksums, never file contents.

** How it works:

1. ==pack== scans the base directory with =find=, pruning excluded directories
   and selecting files named =.env= or =.env.*=, except template files such as
   =.env.example=, =.env.sample= and =.env.template=.
2. Paths are sorted deterministically, copied into a staging directory, hashed
   and recorded in =manifest.tsv=.
3. The staging directory is packed into a =tar.gz= archive with the manifest.
4. ==restore== validates the archive, reads the manifest in order, backs up
   existing files, writes each file back to its absolute path and records a
   journal.
5. ==undo== reads the latest journal in reverse order, puts backups back,
   removes files that were created by the restore and clears the journal.
6. A summary shows packaged/restored, backed up, skipped and failed counts.
