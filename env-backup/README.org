* env-backup

Find, package and restore =.env= files across multiple projects.

The command scans a base directory (including subdirectories), collects every
=.env= and =.env.*= file in a deterministic order, stores them in a =tar.gz=
with a manifest, and can later put each file back at its original absolute path.

** Usage:

#+begin_src bash
env-backup pack    -d <directory> [-o archive.tar.gz] [-r depth] [-x "dir1,dir2"] [-e "pattern1,pattern2"] [-n] [-l logfile]
env-backup restore -a <archive.tar.gz> [-f] [-n] [-l logfile]
env-backup list    -a <archive.tar.gz>
env-backup help
#+end_src

** Commands:

| Command   | Description                                                          |
|-----------+----------------------------------------------------------------------|
| =pack=      | Find and package =.env= / =.env.*= files in a deterministic order      |
| =restore=   | Restore the packaged files to their original absolute paths          |
| =list=      | Show the files contained in an archive                               |
| =help=      | Show the help message                                                |

** Pack options:

| Option          | Description                                                                  |
|-----------------+------------------------------------------------------------------------------|
| =-d <directory>=  | Base directory to scan (default: current directory)                          |
| =-o <file>=       | Output archive path (default: =env-backup-<base>-<timestamp>.tar.gz=)          |
| =-r <depth>=      | Maximum search depth (default: unlimited)                                    |
| =-x "dir1,dir2"=  | Additional directories to exclude (comma-separated)                          |
| =-e "p1,p2"=      | Extra file glob patterns to exclude, e.g. ="*.example,*.sample"=               |
| =-n=              | Dry-run mode (list files without creating the archive)                       |
| =-l <logfile>=    | Log output to file                                                           |
| =-h=              | Show help message                                                            |

Default excluded directories: =.git=, =node_modules=, =vendor=, =dist=,
=build=, =venv=, =.venv=, =__pycache__=, =.cache=.

Default excluded patterns: =*.bak= and =*.bak.*= (used by restore backups).

** Restore options:

| Option          | Description                                                                  |
|-----------------+------------------------------------------------------------------------------|
| =-a <file>=       | Archive to restore                                                           |
| =-f=, =--force=    | Restore even if the checksum does not match                                  |
| =-n=              | Dry-run mode (show actions without writing)                                  |
| =-l <logfile>=    | Log output to file                                                           |
| =-h=              | Show help message                                                            |

** Examples:

Package every =.env= under =~/projects=:
#+begin_src bash
env-backup pack -d ~/projects
#+end_src

Choose the output file and exclude extra directories:
#+begin_src bash
env-backup pack -d ~/projects -o ~/envs.tar.gz -x "node_modules,.git,tmp"
#+end_src

Preview what would be packaged, excluding template files:
#+begin_src bash
env-backup pack -d ~/projects -e "*.example,*.sample" -n
#+end_src

List the contents of an archive:
#+begin_src bash
env-backup list -a ~/envs.tar.gz
#+end_src

Preview a restore:
#+begin_src bash
env-backup restore -a ~/envs.tar.gz -n
#+end_src

Restore the files to their original locations:
#+begin_src bash
env-backup restore -a ~/envs.tar.gz
#+end_src

** Archive format:

#+begin_src text
manifest.tsv
README.txt
files/<relative-path>
#+end_src

=manifest.tsv= is a tab-separated file. Its first lines are comments with the
base directory and creation date, followed by one line per file:

#+begin_src text
INDEX  ABSOLUTE_PATH  RELATIVE_PATH  SIZE  SHA256  MODE  MTIME  ARCHIVE_PATH
#+end_src

Files are sorted with =LC_ALL=C sort= on their relative paths, so the order is
stable across runs and restores follow that same order.

** Restore behavior:

1. The archive is extracted to a temporary directory and its members are
   validated (no absolute paths, no =../= traversal, only expected members).
2. Each entry in =manifest.tsv= is processed in order.
3. If a destination file already exists, it is renamed to
   =<file>.bak.<timestamp>.<index>= before writing.
4. The SHA-256 stored in the manifest is verified. On mismatch the file is
   skipped unless =-f= / =--force= is used.
5. Parent directories are created as needed and the original mode is restored.

** Security notes:

- Archives contain secrets in plain text. The script creates them with mode
  =600=, but you are responsible for storing and transferring them safely.
- The restore operation writes to the original absolute paths recorded at pack
  time. Make sure the environment is the one you expect.
- Use =-n= to preview both =pack= and =restore= before running them for real.
- Existing files are backed up during restore, not deleted.

** How it works:

1. ==pack== scans the base directory with =find=, pruning excluded directories
   and selecting files named =.env= or =.env.*=.
2. Paths are sorted deterministically, copied into a staging directory, hashed
   and recorded in =manifest.tsv=.
3. The staging directory is packed into a =tar.gz= archive with the manifest.
4. ==restore== validates the archive, reads the manifest in order, backs up
   existing files and writes each file back to its absolute path.
5. A summary shows packaged/restored, backed up, skipped and failed counts.
